## ⚡ How It Works

The bot watches live prices on Polymarket and Kalshi. When it sees a price difference that offers a possible profit, it buys on the lower-priced platform and sells on the higher-priced one. This process is called arbitrage.

Doing this quickly in 15-minute markets helps you take advantage before prices align again.
